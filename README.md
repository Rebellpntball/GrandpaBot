# GrandpaBot

Community bot for **Grandpa's Fresh Dayz Servers** — based on [RebellsBot](https://github.com/Rebellpntball/RebellsBot).

**Grandpa Coins** · shared market · orders · Xbox + Steam DayZ

## Servers

**Xbox PVE:** Chernarus · Livonia · Frostline Sakhal  
**Xbox PVP:** 10XLOOT Chernarus · Prison Deathmatch  
**Steam:** Vanilla+ Laid Back PVE · Scifi

## Setup

```bash
git clone https://github.com/Rebellpntball/GrandpaBot.git
cd GrandpaBot
cp .env.example .env
cp config/servers.grandpas.js config/servers.js
npm install && npm run deploy && npm start
```

`/seedcatalog` then `/shop`. Stay fresh.
